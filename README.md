# Karlakliniken

Källkod för Karlaklinikens hemsida (statisk sida, en fil: `index.html`).

## Redigera innehåll

Öppna `index.html` och sök efter text inom `[hakparenteser]` — det är platshållare som ska ersättas med riktig information (adress, telefon, personal, priser, öppettider m.m.).

## Driftsättning

Sidan är statisk HTML/CSS/JS och kan driftsättas direkt via valfri statisk hosting (t.ex. GitHub Pages, Netlify eller Cloudflare Pages) genom att peka på detta repo.
